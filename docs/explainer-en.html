How it works

1 · SCRIPT

Reads the Markdown

Splits the document into sections with line numbers. Long code blocks shrink to one line.

0 tokens
→
2 · AI (SONNET)

Writes notes

A small JSON: a summary per section, decisions with their why and, where it helps, a flow.

~2k output tokens
→
3 · SCRIPT

Builds the HTML

Checks the notes and writes the whole page: styles, diagrams, review controls.

0 tokens
→
4 · YOU

Review

OK or Change with a note on each section. One button copies it all to paste back to Claude.

The AI can't make things up: every decision and every flow step must cite the spec lines it comes from. Anything without real line numbers is dropped by the script. The full text is always right below.

What the page gives you

Section summaries AIWhat each part decides or delivers, in one line.
Decisions AIWhat's worth pushing back on: X over Y, limits, what's left out.
Flow diagrams AIOnly where there are ordered steps or branches. Otherwise, none.
Guided review CODEProgress, OK / Change, notes saved in the browser.
Full text CODETables, code and lists nicely formatted, light and dark.
Long plans CODEOne section per task, with code folded away.

Install

1

Download spec-review.zip from the message and unzip it into your skills:

unzip spec-review.zip -d ~/.claude/skills/
2

In Claude Code, give it a spec or a plan:

/spec-review docs/specs/my-feature.md
3

Open the .review.html next to the file. Options:

--fast     Haiku, cheaper
--no-ai    no AI, formatting only
--lang en  English page labels

Needs Node 18 or newer. No dependencies, no plugins.
