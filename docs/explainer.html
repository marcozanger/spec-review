Cómo funciona

1 · SCRIPT

Lee el Markdown

Parte el documento en secciones con números de línea. El código largo se resume en una línea.

0 tokens
→
2 · IA (SONNET)

Escribe notas

Un JSON chico: resumen por sección, decisiones con su porqué y, si hace falta, un flujo.

~2k tokens de salida
→
3 · SCRIPT

Arma el HTML

Valida las notas y escribe toda la página: estilos, diagramas, revisión.

0 tokens
→
4 · VOS

Revisás

OK o Cambiar con una nota en cada sección. Un botón copia todo para pegarle a Claude.

La IA no inventa: cada decisión y cada paso del flujo tiene que citar las líneas de la spec de donde sale. Si no cita líneas reales, el script lo descarta. Y el texto completo siempre está debajo.

Qué te da la página

Resumen por sección IAQué decide o entrega cada parte, en una línea.
Decisiones IALo discutible: X en vez de Y, límites, lo que queda afuera.
Diagramas de flujo IASolo donde hay pasos en orden o ramas. Si no, no hay diagrama.
Revisión guiada CÓDIGOProgreso, OK / Cambiar, notas guardadas en el navegador.
Texto completo CÓDIGOTablas, código y listas con buen formato, en claro y oscuro.
Planes largos CÓDIGOUna sección por task. El código va plegado.

Cuánto cuesta

Spec típica, Sonnet~$0.10
Plan grande, Sonnet~$0.15
Con --fast (Haiku)~$0.01
Volver a armarla si el .md no cambió$0

Precio de API. Con suscripción gasta cuota, no dólares.

Instalarlo

1

Bajá spec-review.zip del mensaje y descomprimilo en tus skills:

unzip spec-review.zip -d ~/.claude/skills/
2

En Claude Code, pasale una spec o un plan:

/spec-review docs/specs/mi-feature.md
3

Abrí el .review.html que queda al lado del archivo. Opciones:

--fast   Haiku, más barato
--no-ai  sin IA, solo formato
--lang en  etiquetas en inglés

Necesita Node 18 o más nuevo. Sin dependencias ni plugins.
